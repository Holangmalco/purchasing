    💼 구매부서 유틸리티 (PDF 종합 도구 & 파일명 복구) 사용 안내서
========================================================================

■ 기능 요약
  [탭 1] 📑 PDF 종합 도구 (100% 오프라인 / 사내 보안 걱정 제로!)
    1. 📷 사진 & 서류 ➡️ PDF 변환:
       - 사진(JPG, PNG, WEBP 등) 및 서류(Word, Excel, HWP, 텍스트)를 PDF로 변환
       - 【엑셀 맞춤 기본 탑재】 엑셀 표 가로 잘림을 방지하는 [너비 1페이지 맞춤]이 기본 적용되어 깔끔하게 변환 (시트 전체 1장 맞춤 / 원본 유지 선택 가능)
       - 【기본 설정】 여러 장을 한 번에 끌어다 넣으면 각 파일별로 "각각 1장씩 개별 PDF"로 신속 변환
       - 1개의 합본으로 묶길 원할 때는 상단 옵션 [여러 장의 사진을 1개의 합본 PDF로 묶어서 저장]에 체크
       - 스마트폰 사진 EXIF 방향 자동 회전 탑재 (누워있는 사진 똑바로 보정)
    2. 📑 여러 PDF 하나로 합치기 (병합):
       - 흩어져 있는 여러 개의 PDF를 순서대로 1개의 깔끔한 합본으로 통합 (파일명 정렬 지원)
    3. ✂️ 페이지 분할 & 특정 페이지 추출:
       - 원하는 페이지 번호(예: 1-3, 5)만 쏙 추출하거나, 1장씩 낱개로 모두 분할
    4. 📉 PDF 용량 다이어트 (압축):
       - 스캔본 및 고해상도 사진 PDF를 화질 저하 없이 메일 첨부용으로 용량 절감
    5. 🔄 PDF 방향 똑바로 회전:
       - 스캐너로 잘못 스캔되거나 돌아간 PDF 문서를 90도/180도 일괄 회전

  [탭 2] 🛠️ 한글 파일명 복구 (맥북 자소 분리 복구)
    1. 맥북(macOS) 문서의 한글 자소 분리(ㅎㅏㄴㄱㅡㄹ) 윈도우 완성형(NFC) 원복
    2. 메신저/웹 다운로드 시 발생하는 호환용 자모(ㄱ, ㅖ, ㅇ, ㅑ, ㄱ...) 결합
    3. 압축 해제 시 발생하는 외계어 인코딩(Mojibake) 오류 안전 복구
    4. 영문, 숫자, 특수문자, 괄호, 공백, 확장자는 100% 원본 그대로 보존

■ 사용 방법 안내
------------------------------------------------------------------------

[방법 1] 열려 있는 프로그램 창에 파일 직접 던지기 (강력 추천!)
  1. '구매부서_유틸리티.exe'를 더블클릭하여 창을 엽니다.
  2. 프로그램 실행 시 실무에서 가장 많이 쓰이는 [탭 1] PDF 종합 도구가 첫 화면으로 열립니다!
     - [탭 1] PDF 종합 도구:
       * 변환, 합치기, 분할 등 원하는 모드를 누르고 파란 상자(📥)로 대상 파일을 던지면 즉시 처리!
       * 사진을 여러 장 넣으면 기본적으로 각각 개별 PDF로 변환됩니다.
     - [탭 2] 파일명 복구:
       * 깨진 파일이나 폴더를 파란 상자(📥)로 드래그 & 드롭하면 1초 만에 복구!

[방법 2] 바탕화면 아이콘에 툭 던지기 (파일명 복구 전용)
  1. 프로그램 창 [탭 2]에서 [📌 바탕화면 바로가기 생성] 버튼을 누릅니다.
  2. 바탕화면에 '구매부서 유틸리티' 바로가기 아이콘이 생깁니다.
  3. 깨진 파일이나 폴더를 이 아이콘 위로 툭 끌어다 놓으면 1초 만에 복구됩니다.

[방법 3] 마우스 우클릭으로 1초 만에 복구 (파일명 복구 전용)
  1. 프로그램 창 [탭 2]에서 [✨ 우클릭 메뉴 등록] 버튼을 누릅니다. (최초 1회)
  2. 파일 탐색기에서 깨진 파일이나 폴더를 '마우스 우클릭'합니다.
  3. 메뉴에서 [[구매부서 유틸리티] 한글 파일명 복구]를 누르면 즉시 복구됩니다!

■ 회사 및 타 PC에서 사용하는 방법
------------------------------------------------------------------------
  - 이 '구매부서_유틸리티' 폴더를 통째로 USB나 사내 드라이브로 복사해 사용하실 수 있습니다.
  - 파이썬이 설치되어 있지 않은 일반 PC에서도 100% 정상 작동하는 단일 실행 파일입니다.
  - 외부 인터넷 사이트(iLovePDF 등)에 문서를 업로드하지 않고 100% 로컬에서 처리되므로
    사내 기밀 서류나 개인정보가 포함된 계약/견적 문서도 안심하고 작업하실 수 있습니다.
